<p class="wp-block-paragraph">These three terms are often confused.</p>

<h2 class="wp-block-heading" id="step-6-create-your-github-repository">Step 6: Create Your GitHub Repository</h2>



<p class="wp-block-paragraph">Once the website works locally, create a GitHub repository.</p>



<p class="wp-block-paragraph">GitHub provides a place to store the project’s source code and its version history.</p>



<p class="wp-block-paragraph">For example:</p>



<pre class="wp-block-code"><code>my-business-website</code></pre>

<p class="wp-block-paragraph">Because your website will change.</p>



<p class="wp-block-paragraph">You want to know:</p>



<ul class="wp-block-list">

<li>When did it change?</li>



<li>Who changed it?</li>



<li>Can I restore an earlier version?</li>
</ul>

<h2 class="wp-block-heading" id="a-record-vs-cname">A Record vs CNAME</h2>



<p class="wp-block-paragraph">This distinction matters.</p>



<h3 class="wp-block-heading">A record</h3>



<p class="wp-block-paragraph">An A record points a hostname toward an IP address.</p>



<pre class="wp-block-code"><code>Domain
  ↓
IP address</code></pre>



<h3 class="wp-block-heading">CNAME</h3>



<p class="wp-block-paragraph">A CNAME points one hostname toward another hostname.</p>



<pre class="wp-block-code"><code>www.example.com
       ↓
another hostname</code></pre>



<p class="wp-block-paragraph">Your required configuration depends on your hosting and DNS setup.</p>



<p class="wp-block-paragraph">Don’t add random DNS records just because you found them in a tutorial.</p>



<h2 class="wp-block-heading" id="what-if-your-domain-doesnt-work-immediately">What If Your Domain Doesn’t Work Immediately?</h2>

<ol start="1" class="wp-block-list">

<li>DNS provider</li>



<li>Nameservers</li>



<li>Record type</li>



<li>Record value</li>



<li>Conflicting records</li>



<li>Vercel domain status</li>



<li>SSL status</li>
</ol>



<p class="wp-block-paragraph">DNS changes may not appear everywhere immediately because DNS resolvers and caches can retain previous information.</p>



<p class="wp-block-paragraph">If you’ve checked everything and still can’t get the domain working, this is another situation where professional assistance can save hours.</p>
